# Workspace Organization

A practical operating guide for this vault.

## Folder Intent

- `Inbox/`: temporary captures only. Nothing stays here after processing.
- `Guides/`: reusable playbooks and references.
- `Todo/`: active commitments with deadlines.
- `Projects Description/`: project execution and resume-ready outcomes.
- `Data Engineering/`, `Spark/`, `SQL/`, `System Design/`, `DSA/`: permanent technical knowledge.
- `90_day_1hour_challenge/`: daily challenge logs and solved pattern notes.

## Naming Rules

- Use descriptive names, not placeholders.
- Preferred format for time logs: `YYYY-MM-DD.md`.
- Preferred format for topic notes: `Topic - Subtopic.md`.
- Avoid creating `Untitled.md`; rename it in the same session.

## Daily Workflow (10-15 min)

1. Capture raw content in `Inbox/` using the LinkedIn template.
2. Process each capture into one destination note.
3. Add one concrete next step in `Todo/` or `Projects Description/todo.md`.
4. Link the new note from `index.md` only if it is high-value.

## Weekly Maintenance (20-30 min)

1. Empty `Inbox/` into permanent folders or delete low-value noise.
2. Rename generic files (`Untitled.md`, `Day 1.md` if too vague).
3. Archive completed TODO items with a short outcome line.
4. Keep no more than 5 items in each active TODO list.

## Note Quality Standard

Each permanent note should answer these:

- What problem is this solving?
- What are the key insights?
- What is the next action?

If a note does not answer at least one of these, archive or delete it.
